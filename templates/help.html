How to use this site

A little guide to finding, reading, and cooking from JoLene's recipes.

1

Find a recipe

From the homepage, browse recipes by category — each illustrated seed packet represents one family of recipes. Click any card to see every recipe in that category.

On mobile, tap the menu icon (☰) in the top-right corner to jump directly to any category.

2

Search for something specific

Use the search bar in the top navigation to find a recipe by name or ingredient. Start typing and matching recipes appear instantly — click any result to open it.

On mobile, search is available in the top navigation bar. Tap the search field and start typing.

3

Read a recipe

Every recipe page has three parts:

  • Ingredients — listed on the left (or at the top on mobile). On a tablet or computer, this panel stays in place as you scroll through the steps.
  • Instructions — numbered steps on the right. Each step is one clear action. If a recipe has multiple components (like a frosting or sauce), they are clearly labelled as separate sections.
  • Notes — a pink-bordered box beneath the steps. This is where you'll find tips, substitutions, make-ahead guidance, and family asides.

Recipe tags (like Easy, Make-ahead, or Vegetarian) appear near the top of each recipe. On a category page you can click a tag to filter the list.

4

Print a recipe

Every recipe page is print-ready. Press Ctrl + P on Windows or ⌘ + P on a Mac to open the print dialog. The navigation, background, and decorative elements are automatically hidden so only the recipe text prints cleanly.

✎

Adding or editing recipes

If you have admin access, sign in using the Sign in button in the top navigation (or the menu on mobile). From the admin dashboard you can add, edit, and import new recipes.

Not sure how to use the admin tools? See the admin guide on GitHub.
